# 实验记录格式 v1

保存/加载/CSV 按钮在顶部“实验记录”栏。文件选择器允许选择本地路径。JSON 先写临时文件，写入成功后替换目标；加载失败保留当前有效实验。

`format=ChemLab`、`view_schema=1`。`science` 包含科学模型版本、IPhreeqc 版本、两个独立数据库 SHA-256、顺序操作日志、各步读数、自由落体与当前物理实验参数/时间。加载用固定版本的原始数据库从初始状态重放白名单操作，重新计算平衡化学读数；不接受 PHREEQC 脚本或任意 RAW 状态。版本不符拒绝加载，求解失败不提交部分状态。

`view` 保存器材种类/编号/位置、指示剂、选中源和目标、当前实验模式、相机、操作发生时间及保留曲线。位置、碰撞、容量、时间与操作日志交叉检查。加载后所有实验暂停；继续或重复按钮仍可使用。未应用的输入框草稿不属于已保存的科学状态。

CSV 是本次化学操作的规范读数，以及当前自由落体和当前物理模型保留的曲线。列包含单位（如 `volume_ml`、`Na_mol`、`time_s`、`energy_j`），每行带模型版本和数据库校验值。CSV 数值最多保留 10 位有效数字，以稳定导出精度屏蔽 JSON 往返的末位浮点差异；这些位数不是科学准确度承诺，模型精度见各实验说明。化学操作时间是实验台时钟，物理曲线时间是各独立模型的模拟时钟，不能混成同一反应速率曲线。溶解/沉淀步骤只表示最终平衡，不表示实际反应时间。

限额：16 MiB 文件、每次实验最多 5000 条化学操作、12 件容器；物理曲线保留最近 1200 点，自由落体在支持范围内最多约 760 点。切换物理模型或重新应用动态模型参数会开始新曲线；透镜可保留物距扫描。CSV 不声称包含已丢弃的历史。科学状态按固定模拟步保存；小于一个步长的待累计墙钟余量不保存。

验证：`godot/tests/session_native.gd` 检验溶液/固体/气体账本重建、版本不兼容和中途失败；`godot/tests/session_flow.gd` 在真实 Metal 渲染器中检查文件选择器接线、保存/重置/恢复、器材/指示剂/曲线、CSV 字节一致以及恢复后继续运行。

加热模型另保存最多 512 条按时刻排列的控制记录；曲线采样保存对应控制历史的长度，确保同一时刻调温/开关前后的读数仍能按原版本还原。初始水样参数保持独立。旧 `physics-0.1` / `physics-0.2` 保存文件会明确提示版本不兼容。详见 [加热说明](HEATING_AND_STIRRING.md)。

0.2 修正版模型标识为 `aqueous-0.3+kinetics-0.1+batch-0.1+barite-0.1+physics-0.3+combustion-0.1`。`view.beginner` 另存目录 ID、器材位置、有限固体库存、接收物内容、接口连接、夹具关系、秒表与视角。容量和原生容器绑定交叉校验；最多 60 件物品、128 条连接。可选 `science.flame_field` 保存完整固定尺寸空间场、时钟与守恒账本；加载校验非负库存、数值范围和燃烧源一致性。

新增 `science.pitzer_sha256` 与 `science.kinetics`：每容器两区的体积、H⁺/OH⁻ 摩尔数、模拟时钟、速率/反应量、有效活度参数和当量账本。重放化学日志后检查模型参数及总库存一致，再恢复动态状态。版本、数据库身份、非有限或不守恒库存不符时拒绝。

`view.kinetic_history` 每容器最多 1200 点，另保存当前交换流量和图模式。每个容器的时间是实际动力学积分时间，重新配液重置；等待求解或暂停不增加时间。采样历史是保存的数据，不是由完整交换流量控制历史重新算出；只校验尺寸、数值范围和时间顺序，不声称历史曲线已独立重演验证。

CSV 另含 `neutralization_kinetics` 行，记录 `time_s`、上下部 pH、`rate_mol_s`、探头区域及模型说明。原平衡行与动力学行分开。浓溶液模型、两区近似及通过的定向保存/CSV 检查见 [中和动力学](REACTION_DYNAMICS.md)。
