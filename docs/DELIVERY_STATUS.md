# 交付状态

本项目按原目标的阶段完成可验证的限定实现；用户批准从 Unreal 改用 Godot，原创代码保留 AGPL-3.0-only，并授权公开 GitHub 仓库。后续要求的可调温加热、独立搅拌、酒精灯、本生灯、氢氧焰、乙炔氧焰和酒精喷灯已加入。

| 阶段 | 已实现与验证的内容 | 保留的边界 |
|---|---|---|
| 0 | 固定版本 Godot / godot-cpp / IPhreeqc、Apple Silicon C++ 编译运行、许可决策、30 项原料矩阵 | 使用用户批准的 Godot 路线 |
| 1 | 中文房间与实验台、器材、选择拖动/观察、碰撞、原料搜索 | 化学台玻璃搅拌棒为观察道具；主动搅拌在专门实验台 |
| 2 | 基础组及支持溶液的配制、酸碱中和、连续守恒转移、pH 和指示剂 | 稀溶液、25°C、明确混合白名单 |
| 3 | 可调高度/重力的自由落体、固定时钟、落地前后区分 | 忽略空气阻力，不模拟任意接触碰撞 |
| 4 | 透明玻璃壳、重力液面、体积近似、受控倾倒、水流 | 视觉近似已核对，不是实物光学标定或流场求解 |
| 5 | 有限 Calcite / Gypsum、CO₂ 开放/封闭平衡、清液分离 | 仅验证的气液固模型；没有达到 20 项全支持 |
| 6 | BaCl₂ / Na₂SO₄ 的 Barite 沉淀、过量/未饱和核对 | 总计 17/30 原料操作可用，13 项明确禁用 |
| 7 | 弹簧、单摆、两水体热交换、直流电路、薄透镜；另加水加热与搅拌 | 各自限定模型；六种热源按给定有效功率传热，不模拟燃烧 |
| 8 | 版本化 JSON、操作与控制历史回放、暂停恢复、CSV、错误保留 | 模型版本不兼容会拒绝；历史长度有明确上限 |
| 9 | 独立 arm64 macOS 应用、许可证、构建收据、性能与重复操作验证工具 | 最终实测结果见性能报告；未经 Apple 公证 |

## 验证证据

- `artifacts/verification.json`：7 个原生 CTest 案例，Godot 导入、2 个无窗口原生/保存流程、8 个渲染交互流程，包括新增 `heater_flow`。检查 PASS 标记、退出状态、脚本错误和泄漏警告。
- `artifacts/packaged-smoke.json`：发布运行程序从 PCK 加载数据库与原生库、化学平衡/守恒、热模型与保存恢复；无窗口数据不用于帧率。
- `artifacts/build-receipt.json`：源文件身份、应用文件 SHA-256、arm64 架构、临时签名校验。
- `docs/PERFORMANCE.md`、`artifacts/performance-*.json`：编辑器引擎和独立应用的实际渲染计时、内存、响应与重复生命周期记录。

所有未支持原料及其缺失数据保留在 [支持矩阵](SUPPORT_MATRIX.md)。缺失数据库条目或未通过价态验证的原料没有被图标、火焰外形或硬编码数值替代。17/30 是当前实际数量，未声称完整支持 30 种或任意组合。
