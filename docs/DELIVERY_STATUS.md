# 0.2 交付状态

Godot / C++ / IPhreeqc 的中文实验室，原创代码 AGPL-3.0-only。用户授权公开源码、提交和推送，要求新手模式、全部参考器材与药品目录、燃烧热化学和可开关三维燃烧场。

| 模块 | 已实现 | 适用边界 |
|---|---|---|
| 新手实验区 | 分类搜索、大卡片、摆放、旋转、取用、连接、称量、引导、记录 | 12 个求解器容器、60 件物品、128 条连接 |
| 173 项器材 | 全部参考器材及容量变体；81 种原创几何族和缩略图 | 部分专用装置仅支持摆放/接口关系，未计算其专用过程 |
| 143 个固体包装 | 含粉末、颗粒、片状及水合物变体；有限干态质量取用与转移 | 不等于 143 项可反应化学品；未知反应明确阻止 |
| 水溶液/气液固 | 原有 17/30 项支持，酸碱、限定盐溶液、CO₂、Calcite/Gypsum、Barite | 25°C、五种强电解质至 1 M，其余稀溶液及混合白名单 |
| 中和动力学 | 两区 H⁺/OH⁻ 反应、有限交换、pH/速率时间图、换源滴定序列 | 水及 HCl/NaOH/KOH/NaCl/KCl；高浓度速率常数外推未标定；非三维反应流场 |
| 玻璃器材 | 独立烧杯壶嘴与刻度、试剂瓶肩颈瓶塞、内腔体积与倾斜裁剪 | 参数化几何和薄壁光学近似，未作实物标定 |
| 物理实验 | 自由落体、弹簧、单摆、热交换、直流、薄透镜、加热搅拌 | 各自限定模型，未实现任意接触或流体运动 |
| 燃烧热化学 | 有限燃料、供氧、产物、焓平衡、绝热温度、耗尽停热 | 16 物种常压理想平衡；捕获比例固定，未进行实物标定 |
| 三维燃烧场 | 可开关速度/燃料/氧/温度场及体积渲染、守恒收支、恢复 | 粗网格与经验单步反应，不是精细燃烧 CFD |
| 保存/导出 | 版本检查、原生状态回放、器材/库存/连接/场恢复、暂停加载、CSV | 旧科学模型版本不兼容，损坏文件保留当前状态 |
| 独立程序 | arm64 macOS App，数据、资源与许可打包，签名校验 | 本地临时签名，未经公证，未上传 GitHub Release |
