# 加热与搅拌

在「物理实验 → 加热与搅拌」选择电热板、酒精灯、本生灯、氢氧焰、乙炔氧焰或酒精喷灯。六项是器材与热源外形，不增加原料支持数量。水样、温度探头、支架和独立电动搅拌桨由同一实验状态驱动。

## 操作

- 水样质量 0.05–0.25 kg，初温 5–90°C；修改初始条件后「应用参数并重置」。
- 目标水温 25–95°C、有效热功率 50–1000 W、搅拌转速 0–600 rpm。「应用温度 / 功率 / 转速（不重置）」即时生效，保留当前温度、累计能量和转数。
- 「开启 / 关闭加热」和「开启 / 关闭搅拌」各自独立。开关操作恢复实验时钟；全局「暂停」冻结时间与运动。
- 到达目标后，理想反馈控制器只提供抵消散热的功率。下调目标时先停止供热，按环境散热降温，不瞬间把水温改为设定值，也不主动制冷。
- 关闭加热继续散热。停止搅拌保留已转圈数。旋转相位使用模型积分的转数，暂停、恢复、变速均连续。
- 设定温度是探头测量的水温，**不是火焰温度**。颜色和火焰轮廓只是外观；没有据此估算燃烧温度。

## 热模型与来源

采用集总、内部均温的液态水模型，水的固定比热近似 c=4186 J/(kg·K)，环境温度 20°C，固定散热热导 K=0.6 W/K。方程为：

```
C = mc
C dT/dt = P − K(T − 20°C)
ΔU = C(T − T₀)
Qinput − Qambient = ΔU
```

每段恒定控制以解析指数解推进。低于目标时使用功率上限；首次到温的交点精确求解，随后 P=K(Tset−20°C)；高于目标时 P=0，降到目标后恢复保温。固定 1/120 s 模拟时钟，与渲染帧率无关。控制变化按时间顺序分段积分，历史输入能量不会用新功率回算。

六种热源共用**指定的有效传热功率**，这是实验输入，不是由真实设备型号、燃料流量、喷嘴、火焰或容器几何推导的额定功率。火焰器材配有此虚拟实验的理想温度反馈截止器，不代表手持灯具自身具备恒温功能。本模块不模拟燃烧产物、气体混配、压力、火焰传播或燃料消耗，也不提供真实点火或操作步骤。

比热与 Q=mcΔT 的来源：[OpenStax University Physics 2，1.4](https://openstax.org/books/university-physics-volume-2/pages/1-4-heat-transfer-specific-heat-and-calorimetry)。传热与温差关系参考：[1.6](https://openstax.org/books/university-physics-volume-2/pages/1-6-mechanisms-of-heat-transfer)。K、温控策略及源功率范围是本虚拟实验明确选定的模型参数，未声称经过实物设备标定。

忽略容器与加热板热容、蒸发、沸腾、热膨胀、搅拌机械功转热及空间温度梯度。均温假设独立于搅拌开关；转速不被用来编造传热系数、浓度场或反应速率。搅拌桨按设定转速运动，未求解黏性流体、涡流或磁耦合失步。高温射流对材料的热冲击也未求解，因此器材图示不应当作实物布置的工程验证。

该模块是独立的水加热实验。现有化学样品保持 25°C 的已验证平衡条件，不把热源外形当作已经支持高温化学、燃烧或任意反应。

## 保存与验证

模型版本为 `physics-0.2`；控制历史每项包含时间、目标水温、功率上限、转速、热源编号和两个开关，最多 512 项。初始水样参数与控制历史共同重建最终状态；加载后暂停，历史曲线按各采样时刻对应的控制版本重算。CSV 同时包含控制信息、温度、输入热量、环境散热、内能变化、转速和转数。

`tests/physics_models_test.cpp` 用独立小步积分对照解析温升，核对恒温功率、冷却曲线、六类热源的 95°C 上限、输入/散热/内能账、变速和暂停、控制历史回放，以及 30/60/144 FPS 时间分割一致性。

`godot/tests/heater_flow.gd` 覆盖真实界面处理器、六项器材切换与渲染、运行中调温、独立加热/搅拌开关、旋转姿态、保存恢复与 CSV 一致性，并拒绝越界目标温度。实际执行结果见 `artifacts/verification.json`；截图为 `artifacts/heater-0.png` 至 `heater-5.png`。
