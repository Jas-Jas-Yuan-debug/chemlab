# 三维与液体视觉的验证边界

器材采用米为几何单位。烧杯、量筒、滴管、试剂瓶分别拥有容量、半径、高度；液面高度由实际 mL 转换为 m³，再通过内腔截锥积分反求高度。刻度沿同一积分关系布置。烧杯具有壶嘴，试剂瓶具有肩部、窄颈和独立瓶塞，详见 [器材修正](REACTION_DYNAMICS.md)。容器侧壁与底、内外表面分别建模；没有把玻璃当实心柱。

受控倾倒：源容器先移至接收容器上方，按当前填充量寻找液面达到低侧杯沿的角度。姿态接近目标后才请求物质转移。流量以 mL/s 表示，后台串行处理；水流只在最近一次转移成功时显示，空/满、错误或松手停止继续请求。仍在计算的已接受分样会完成，松手不撤回已接受的科学操作。

液体网格由内腔侧壁和自由表面组成，材质按内腔剖面与局部重力液面裁剪。倾斜体积使用 128 个水平截面的圆弓形面积积分，二分反求液面位置；不修改科学体积。轴对称积分未计入壶嘴局部非轴对称体积，不求解晃动、飞溅、黏度或真实流场。

`godot/tests/pouring_flow.gd` 用独立二维矩形求积积分裁剪后的内腔，核对 5/50/200 mL 与 0/0.5/1.0/1.4 rad 组合，误差门限为 max(0.5 mL, 2.5%)。科学体积与守恒另以更严格的 C++ 测试核对；视觉门限不能冒充测量精度。倾倒中额外检验液面世界法向与重力方向一致、空容器停止、释放按钮停止和氯元素守恒。

玻璃使用 Fresnel 透明度近似；液体颜色只来自标注的指示剂 pH 映射或物理热实验温度图示。没有使用固体颜色猜测溶液颜色。气泡只由专用气液平衡已计算的 CO₂ 释放量驱动；动画时间不表示反应速率。金属、木材、台面、光照和阴影采用性能受控的材质，程序生成的小纹理有固定种子。

可视检查的证据为 artifacts 下的实际渲染截图：器材透明轮廓、液面、受控倾倒、沉淀、CO₂ 顶空、七类物理实验及六种加热器材外形。其结果支持几何/读数/交互的一致性与可读性；尚不是实物照片的光学标定，玻璃折射、弯月面、部分器材外形与教学示意模型仍有简化。
