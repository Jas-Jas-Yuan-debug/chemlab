# 硫酸钡沉淀 · barite-0.1

在沉淀实验页，分别设定 BaCl₂ 与 Na₂SO₄ 两种水溶液的体积和浓度，混合后求与重晶石（Barite，BaSO₄）共存的最终平衡。固定 25°C，每份 1–125 mL、0.00001–0.01 mol/L，总初始体积 ≤250 mL。

只选择 Barite 这一候选固相，初始固体量为零；由求解结果决定是否生成沉淀及其物质的量，不按试剂名称直接生成。没有引入其他数据库，不默认其他固相达到平衡。结果包括残余 Ba/S、沉淀量、pH 和清液体积。白色薄层依据原数据库的 52.9 cm³/mol 换算体积，不是沉降动力学。无成核延迟、胶体或过滤阻力模型。

可分离全部清液并向空烧杯分装；气液固模型中的取样限制同样适用。元素和相的数量是当前库存依据；`ingredients_mol` 仅记录投料来源，不表示溶液中仍存在相应数量的原料分子。

## 验证

- `tests/barite_test.cpp`：3 浓度 × 3 体积 × 3 配比，共 27 组；包含未饱和不沉淀、等量、任一试剂过量、重复、清液分装。
- 检查 Ba/S/H/O 和其他元素守恒，以及硫价态；沉淀不超过限制离子数量，有沉淀时 SI≈0。
- 以 Ksp≈10⁻⁹·⁹⁷ 的理想稀溶液公式独立核对等量案例，允许初始剂量 3% 的活度修正差异；实际结果使用完整数据库的平衡与络合计算。
- `godot/tests/barite_flow.gd` 在实际渲染器中运行浓度/体积设置、沉淀显示、低浓度零沉淀、过量、清液分离和分装。

当前回归例：50 mL、0.001 mol/L 的两种溶液混合，计算生成约 0.0486 mmol BaSO₄，残留液相 Ba 和 S 各约 0.0014 mmol。这是模型回归值，不是外部实测结果。

来源：固定 `phreeqc.dat` Barite 块，行 1016–1021（含平衡温度表达式，原注释引用 Blount 1977、Templeton 1960）。求解边界见 [USGS EQUILIBRIUM_PHASES](https://water.usgs.gov/water-resources/software/PHREEQC/documentation/phreeqc3-html/phreeqc3-13.htm)。
