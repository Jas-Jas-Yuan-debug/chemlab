# 物理模型与验证

## 自由落体（已运行）

球底距台面初始高度 h₀：0.1–2 m；设定重力 g：0.1–20 m/s²；初速度为 0。
向上为正，忽略空气阻力。落地前 h(t)=h₀−gt²/2，v(t)=−gt。
接触发生在 t_hit=√(2h₀/g)，撞击前速率为 √(2gh₀)。落地后采用完全非弹性接触：高度和速度为 0。
不计算球的变形、声响、弹跳或能量转化到房间的过程。

科学时钟在 C++ 中以 1/120 s 步长累计。碰撞时刻用解析事件定位，显示时不把它取整为渲染帧。
暂停冻结模拟时间，重复实验重新设置相同条件。Godot 只读取同一份 C++ 测量状态来放置球、更新读数和曲线。

`tests/mechanics_test.cpp` 已运行：9 组高度/重力参数、轨迹与解析值、碰撞前/后区分、暂停/继续/重置、
输入步进代表 30/60/144 FPS 时保持相同轨迹。这是时间步进验证，不是实测渲染帧率。

`godot/tests/fall_flow.gd` 已实际运行三维窗口：修改高度/重力、释放、暂停/继续、落地、曲线、重复、切回化学保持状态。
案例 h₀=1.5 m、g=2 m/s²：t_hit≈1.225 s，撞击前速率≈2.449 m/s。
物理状态用双精度检查；三维位置因 Godot 的 float32 变换采用 1e-6 m 容差。
